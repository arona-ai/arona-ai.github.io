Arona, a Blue Archive assistant for Discord

Discord bot · Powered by Google Gemini · Fan project

Arona is a Discord AI assistant themed around the Shittim Chest OS from Blue Archive. She chats, searches the web, runs code, looks up student data, and can join voice channels, all while keeping the personality of the game's Arona.

Add Arona to your server, join the support server, or read the source code.

What she can do

  • Memory. Remembers Sensei's preferences across sessions.
  • Multimodal. Understands images, video and audio.
  • Web search. Live browsing and reverse image search.
  • Code execution. Python and shell in isolated Docker containers.
  • Kivotos database. Students, banners, events and raids from SchaleDB.
  • Voice. Voice chat and text-to-speech in Arona's own voice.

Using her

Mention her in any channel, or use the prefix !arona. You can also install her to your account and call /arona anywhere without inviting her to a server. The full command list is in the README.
