Privacy Policy — Arona Bot

Last updated: 2026-07-26

This policy describes the information handled by Arona Bot, a Discord bot powered by the Gemini API.

Information we may process

  • Discord user IDs, display names, guild IDs, channel IDs, and role info as needed for permissions
  • Message content (for AI replies, tool use, and the message-history/vector-search feature)
  • Voice channel state and audio during voice conversations (Arona joins voice calls and speaks using TTS with an RVC-converted voice)
  • User-provided "saved information" key-value entries (facts the user explicitly asks Arona to remember, via the saved_information tool)
  • Account-linking data (migration keys, linked Discord IDs) if you choose to link multiple accounts
  • Chess game state, scheduled reminders/events, and other feature-specific inputs you provide
  • Code or shell commands submitted for the sandboxed code-execution feature, and their output

Server-side retention

  • Saved information (the saved_information/memory tool) is stored persistently in a SQLite database, per Discord user ID, until you delete it or request a full wipe (see below).
  • Message history used for AI context and semantic search is stored persistently (SQLite + vector embeddings), capped at roughly the most recent 600 messages per user, with older messages automatically pruned.
  • Channel/guild memory cutoffs (e.g. !arona clear) are stored as timestamps, not full message logs.
  • Sandbox code execution runs in an isolated Docker container per session; output logs and submitted scripts may be temporarily saved to disk during the run.
  • Account links (if you use the account-linking feature) merge your saved information and message history under a shared root account, and are stored until unlinked.

Third-party transmission

Depending on the feature you use, data may be sent to:

  • Google Gemini API (chat text, images, and tool-use requests) for AI responses
  • Web search (via ddgs) for search queries you trigger
  • SchaleDB for Blue Archive game data lookups
  • Any other third-party APIs a specific feature integrates with

Purposes

We use this data to provide Arona Bot's features, diagnose and fix issues, prevent abuse (including anti-raid protection), and improve response quality. We do not sell your data or use it for profiling/advertising.

Your controls

  • Use the saved_information tool (via chat) to add, edit, or delete individual memory entries.
  • Use !arona clear to stop Arona from reading messages sent before that point in a channel.
  • Use !arona forgetme (then confirm) to permanently delete all saved information, message history, and account-link key associated with your Discord ID. If your account is linked to another account, you'll need to unlink first, since linked accounts share data.
  • Deletion/access requests can also be made by contacting the operator directly (see Contact).

Retention and deletion

Data described above is kept while you use the bot, until you delete it yourself or request removal. There is currently no fixed automatic expiry for saved information or account links beyond the message-history cap described above.
